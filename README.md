# Report IA

Proyecto de práctica con skills de Codex para revisar blogs sobre inteligencia artificial y crear informes acumulativos en HTML.

## Página publicada

https://report-ia.pages.dev/

## Skills del proyecto

- `.agents/skills/report-ia/`: busca noticias de uno o varios blogs sobre un tema y actualiza la página de informes con resúmenes sencillos y una conclusión común.
- `.agents/skills/publicar-report-ia/`: revisa el cambio, lo publica en GitHub y despliega la página compartida en Cloudflare Pages.

## Informes

- `informes/index.html` es la página acumulativa, ordenada por fecha y con filtros por categoría.
- Los informes HTML con fecha son archivos de referencia de revisiones anteriores.

La carpeta `.wrangler/` y los archivos de entorno o credenciales están excluidos del repositorio.
